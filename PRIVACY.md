# Конфиденциальность SGG Local MCP

SGG Local MCP — локальный MCP-сервер для файлов и процессов. В этой версии удалены продуктовая аналитика, установочный tracking, UI-события для аналитики, удалённые feature flags/A/B-тесты, рекламные формы и облачный relay исходного проекта. Сервер не отправляет статистику использования разработчику продукта и не открывает рекламные страницы при запуске.

## Локальные данные

Для выполнения задач сервер читает и изменяет файлы, запускает команды и возвращает результат подключённому MCP-клиенту. Он может сохранять локальную конфигурацию, историю вызовов, счётчики инструментов, диагностические журналы и квитанции импорта файлов. История и журналы могут содержать пути, аргументы, фрагменты вывода и сведения о клиенте. Это пользовательские данные; перед передачей отчёта проверяйте его содержимое.

`get_usage_stats` читает локальные счётчики. `get_recent_tool_calls` возвращает локальную историю подключённому клиенту. Удаление продуктовой аналитики не отключает эту диагностику.

Windows-инфраструктура хранит параметры, runtime, зашифрованные ключи, профили туннеля и состояние в игнорируемом каталоге `.local/`. Существующие пользовательские каталоги конфигурации сохраняются для совместимости. Ключ в DPAPI защищён в контексте Windows-пользователя, но доступен процессам, работающим от его имени.

## Когда используется сеть

Сеть нужна для явно используемых функций:

- MCP-клиент получает запрошенные результаты инструментов; если клиент облачный, данные передаются его провайдеру.
- Настроенный пользователем private OpenAI Secure MCP Tunnel переносит MCP-запросы и ответы между ChatGPT и компьютером.
- `read_file` с URL получает указанный ресурс; `import_chat_file` загружает выбранное изображение по переданному клиентом адресу.
- Установка и сборка загружают Node.js, tunnel-client, npm-зависимости и необходимые исполняемые компоненты из источников, указанных в скриптах и lockfile.
- PDF-рендеринг использует Chrome/Chromium; установка его runtime и внешние ресурсы документа могут требовать сети.
- Запущенные пользователем команды имеют собственное сетевое поведение.

Эти операции выполняют пользовательскую функцию. Они не являются каналом скрытой продуктовой статистики. Локальный режим не обещает блокировать все сетевые соединения операционной системы, сторонних зависимостей или выполняемых команд.

## Управление доступом

Настройте разрешённые каталоги, командную оболочку и клиентские разрешения под свою задачу. Пустой список `allowedDirectories` разрешает доступ ко всей файловой системе в рамках прав процесса. Ограничения файловых инструментов не являются песочницей для произвольных shell-команд.

Для каждого компьютера используйте отдельный tunnel/runtime key. Не копируйте `.local` и ключи между машинами, не добавляйте их в Git. Остановка или удаление локального профиля не заменяет отзыв ключа у его провайдера.
