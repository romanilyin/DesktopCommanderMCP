# Безопасность SGG Local MCP

## Область доверия

SGG Local MCP читает и изменяет файлы и запускает процессы от имени пользователя, который запустил сервер. Это инструмент управления компьютером. Используйте его с доверенным MCP-клиентом и разрешениями, подходящими для задачи.

`allowedDirectories` и `blockedCommands` ограничивают отдельные инструменты, но не заменяют изоляцию ОС. Произвольная команда shell может иметь доступ к другим данным и сети в пределах прав того же пользователя. Для более строгой изоляции используйте отдельную учётную запись, контейнер или виртуальную машину.

## Ключи и состояние

Private Secure MCP Tunnel настраивается отдельно для каждого компьютера. Runtime key хранится в `.local` с защитой Windows DPAPI. Не включайте `.local`, ключи, профили, private URLs и историю вызовов в коммиты или публичные отчёты. Доступ от имени того же Windows-пользователя не считается отдельной границей безопасности.

Сервер не содержит продуктовую телеметрию, удалённые эксперименты или relay исходного проекта. Описание оставшихся сетевых функций и локальной диагностики: [PRIVACY.md](PRIVACY.md).

## Обновления и проверка

Собирайте подтверждённый commit этого репозитория с `npm ci` и проверенным lockfile. Штатная Windows-сборка отключает общие install scripts и отдельно пересобирает необходимые нативные зависимости. После изменения зависимостей выполняются сборка, функциональные проверки и `npm audit`; инструкция — [docs/dependency-maintenance.md](docs/dependency-maintenance.md).

## Сообщение о проблеме

Для воспроизводимой ошибки без конфиденциальных данных создайте [issue в этом репозитории](https://github.com/romanilyin/DesktopCommanderMCP/issues). Укажите commit SHA, платформу, версии Node.js и PowerShell, ожидаемое поведение и минимальные шаги воспроизведения. Не прикладывайте действующие ключи, пользовательские файлы и неотредактированные журналы. Если GitHub предлагает приватное сообщение о vulnerability для этого репозитория, используйте его для чувствительных деталей.
